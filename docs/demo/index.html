让每个研究结论，都能沿证据链走回去。

FinDashboard 把 agent 的量化研究放进一个受控系统：输入在决策时点冻结， 计算与代码在沙箱中运行，样本外门控决定“晋级”还是“登记为负结果”， 实盘交易内核始终由人类掌控。

典型应用场景

在投入资金前，先证明一个因子值得继续。

“

A 股截面动量是否存在稳定、成本后的样本外超额？如果证据不足，停止晋级， 保存失败证据，并阻止后续 agent 无条件重复试验。

研究负责人给 agent 的任务

这不是“生成一个策略然后看收益曲线”的演示。系统要回答三个更重要的问题： 当时能知道什么、运行到底用了什么、结论为什么可以或不可以被相信。

  • 冻结发布和 checksum 锁定数据输入
  • IS / OOS 预注册，揭盲结果不可重做
  • 通过门控才进入组合与模拟；失败结果进入 FINDINGS

操作闭环

一次研究，从输入到结论的六个可审计动作。

蓝色标记是用户操作，灰色字段是系统自动留下的证据。
  1. 01

    操作：选择冻结数据发布

    先固定“当时能看到的数据”。

    在「数据与标的」中查看发布时间、覆盖率、质量门和发布 ID。研究运行只引用已发布版本， 不读取持续变化的上游表；财务观测继续受 available_at ≤ decision_at 约束。

    页面
    数据与标的 / 每日指标
    证据
    release ID · 时间范围 · 复权 · 覆盖率 · 质量状态
    媒体
    总览视频 + 真实状态截图
  2. 02

    操作：定义因子与方向

    把经济假设变成可检查的信号。

    在「因子实验室」查看经济含义、计算口径、数据来源与预期方向；用户因子只有在沙箱执行、 质量门与晋级门全部通过后，才能成为正式策略规格的输入。

    页面
    因子实验室 / 因子目录
    证据
    定义 · 数据来源 · 频率 · 预期方向 · 版本
    媒体
    总览视频 + 真实目录截图
  3. 03

    操作：预注册并运行样本外验证

    先写规则，再揭盲答案。

    「实验与 OOS」冻结训练、验证和最终测试窗口，以及阈值与试验预算。 流程完成只说明实验执行完毕；结论必须读取 oos_outcome，不能把状态标签当作支持证据。

    页面
    实验与 OOS / 实验详情
    证据
    假设 · 时间窗口 · 试验数 · 揭盲状态 · OOS 结论
    媒体
    GIF：实验列表 → 选中真实验证详情
  4. 04

    操作：检查 ResearchRun 血缘

    从结果一路追溯到输入。

    每次运行绑定策略版本、数据发布、费用、组合约束与输出 checksum。 列表保留 completed、rejected、failed、interrupted 等状态，让失败与中断同样可查，而不是只展示“最好的一次”。

    页面
    研究运行 / 概览与绩效报告
    证据
    RR-* · strategy version · manifest · result checksum · artifacts
    媒体
    GIF：运行列表 → 选中真实 lineage 详情
  5. 05

    操作：执行验证门

    系统允许两种正确结局。

    “没有通过”不是 Demo 失败，而是阻止一个不稳健假设继续接近资金。 当前结论注册表已经把 A 股截面价格动量登记为多轮独立证伪；新会话若要重开，必须提出新证据并引用旧结论。

    OOS outcome
    证据支持 组合约束 → 三档资金可行性 → 隔离模拟盘
    证据不足 / 被证伪 FINDINGS 结论注册 → 保留 run → 重测禁令
  6. 06

    操作：晋级到组合与隔离模拟

    只有通过门控的结果，才有下一步。

    组合层执行风险贡献、离散交易与资金可行性；模拟盘只接受已发布策略和 completed ResearchRun 的结构化目标仓位。 本次录制库尚无模拟账户，因此页面如实展示空状态，不伪造权益曲线。

    页面
    组合与风险 / 模拟盘 / 任务中心
    证据
    硬约束结果 · simulation_* 账本 · job 状态与阶段
    媒体
    总览视频 + 当前空状态与审计截图

安全边界

研究、模拟、实盘是三套不同的状态空间。

Agent 可以自主研究，但没有通往实盘交易内核的工具通道。
研究域

可自主执行

冻结数据、因子、回测、OOS、ResearchRun 和报告。

research_* / factor_* / BJ-*
模拟域

独立纸面账本

只消费结构化目标，不连接 Broker，也不会自动晋级。

simulation_* / SIM-*
实盘域

人类掌控

下单、改持仓、Kill Switch 和凭证能力永不注册为 agent 工具。

orders / fills / positions

0.1.0dev 发布口径

这是一个可运行的开发版本，不是收益承诺。

  • 研究与模拟能力可本地运行；页面媒体来自真实本地数据。
  • QMT 真机验证仍被 #22 / #24 / #26 阻塞，不把 mock 结果表述为实盘验证。
  • 本项目不构成投资建议，不提供公开托管交易服务。
