让量化研究能够解释自己。

FinDashboard 允许研究 agent 自主探索，同时让每一项输入、决策和结果都可追溯。证据必须通过冻结数据、样本外验证和组合约束，才能继续接近真实资金。

典型场景

一个 A 股截面信号，是否应该被允许继续晋级？

系统保存负面答案时，应当和保存正面答案一样严谨。
研究任务
检验截面动量能否产生稳定、计入成本后的样本外超额。如果证据不足，停止晋级，保留失败证据，并阻止无条件重复试验。

产品必须回答三个问题。

  1. 01当时能知道什么？

    时点一致的数据与不可变发布。

  2. 02究竟运行了什么？

    版本化策略、manifest、费用、约束与 checksum。

  3. 03为什么相信结论？

    预注册 OOS 门、显式失败与持久审计链。

滚动驱动演示

一个假设，七个可审计操作。

向下滚动时产品窗口会保持定格，证据流程随操作逐步推进。
Research / Data & Instruments
01 / 07冻结当时可知的输入
  1. 01

    选择冻结数据发布

    先固定决策时点能看到什么。

    选择标的范围、日期区间、质量报告和发布 ID。研究只引用不可变发布；财务观测继续受 available_at ≤ decision_at 约束。

    证据
    release ID、checksum、覆盖率、质量 warning
    失败关闭
    bars 主发布缺失任何标的都会阻断运行
  2. 02

    定义因子与方向

    把经济想法变成可审查信号。

    因子目录记录经济含义、计算方法、来源字段、频率、预期方向和已知失效模式。用户代码在通过沙箱与晋级门之前保持隔离。

    证据
    定义、版本、来源、预期方向
    失败关闭
    未激活或未通过的用户因子不能进入策略
  3. 03

    预注册并运行样本外验证

    先写检验规则，再揭盲答案。

    冻结训练、验证、最终测试窗口，以及阈值与实验预算。流程完成只代表实验跑完；是否获得支持必须读取 oos_outcome。

    证据
    假设、窗口、试验数、揭盲状态、结论
    失败关闭
    最终测试只能揭盲一次，不能重做
  4. 04

    检查 ResearchRun 血缘

    从每个结果追溯到完整输入。

    每次运行绑定策略版本、数据发布、费用、组合约束、产物与结果 checksum。rejected、failed、interrupted 和 completed 一样被保留。

    证据
    RR-*、manifest、策略 commit、checksum、产物
    失败关闭
    manifest 漂移或缺少冻结输入会终止执行
  5. 05

    施加组合约束

    证明信号能经受组合现实。

    把通过验证的信号转成目标权重，同时施加集中度、风险贡献、现金、杠杆、离散手数与资金可行性约束。

    证据
    约束集、求解结论、三档资金规模
    失败关闭
    风险贡献不可行时禁止生成研究订单
  6. 06

    晋级到隔离模拟盘

    只把合格目标送入独立账本。

    模拟盘只接受已发布策略和 completed ResearchRun 的结构化目标。它不连接券商、不修改实盘持仓，也不会自动晋级。

    证据
    SIM-*、模拟订单、成交、持仓、资金
    真实状态
    本次录制没有模拟账户，因此如实显示空状态
  7. 07

    检查持久审计链

    让成功、失败、中断和重试都可检查。

    任务中心展示状态、阶段、进度、时间、提交者和稳定 job ID。刷新浏览器不会抹掉执行轨迹。

    证据
    BJ-* ID、状态、阶段、时间戳、审计事件
    恢复
    中断的研究保留重试语义与身份

安全边界

研究、模拟和实盘是不同的状态空间。

Agent 可以自主研究，但不存在通往实盘交易内核的工具通道。
研究域

自主探索
