## 研究目标(2026-09-01 用户设定)

**年化收益 ≥ 15%,最大回撤 ≤ 20%**(Calmar ≈ 0.75)。

证据门按阶梯推进,不上台阶不追加数据成本:

| 阶梯 | 年化目标 | 通过标准 |
|------|----------|----------|
| L1 | ≥ 8% | 任一路线在 OOS(2024-2026)复现正超额,回撤可控 |
| L2 | ≥ 12% | 同一路线完整走通 #57 验证实验 + #219 晋级门 |
| L3 | ≥ 15% | 模拟盘连续运行验证后小资金实盘评估 |

**硬约束**:
- tushare 仅 **2000 积分档**(分级门槛不消耗;1 元 ≈ 10 积分,一年有效);
- **先验证策略可靠性,再投数据成本**(积分升级 / 付费源都必须先过证据门);
- 期货数据主源 = tushare(fut_basic / fut_daily / fut_trade_cal,#395 2026-09-09 实测 2000 档可调,主连双源对照后批量默认源切 tushare);交易所官网爬取降为兜底(2026-09-01 原方案)。

## 路线 A:可转债双低 🔴 → P0 第一优先

- **逻辑**:零边际数据成本(2000 档 `cb_daily`/`cb_basic` + akshare 强赎兜底
  `bond_cb_redeem_jsl`);平台已有 `convertible_double_low` 独立模拟器与
  asset_rules(T+0 / 10 张 / 免印花税 / ±20%),真缺口只有数据接入 +
  convertible instruments 登记发布。
- **落地 issue**:#265(数据链路,已落地 2026-09-08——cb_daily/cb_basic + convertible_profiles + convertible_metrics 发布全通);剩余 = 2024-2026 OOS 复测(策略验证,证据门未过)。
- **警讯(先验存疑)**:2025-12 券商双低组合 **-4.72%** vs 转债指数
  **+2.13%**(标的稀缺 + 强赎潮);2017-2023 文献 15% 年化只当先验,
  **2024-2026 OOS 是唯一裁判**,走 #57 / #219 门。
- **工程坑**:通用 `BacktestEngine` 不传 `instrument_resolver` 时按 A 股股票
  撮合(见 FINDINGS #4),转债接通用管线前必须注入 resolver;双低独立
  模拟器不受影响。

## 路线 B:分钟线 🔴(受数据门约束)

- tushare 2000 档**不可行**(`stk_mins` 需 5000 档 + 单独开权限);
- 先用 akshare 免费分钟(`stock_zh_a_hist_min_em`)对前 300 只做小样本 IC
  验证,**过门再谈积分**;不建全量分钟库(#220 的 240× 结论仍有效)。

## 路线 C:期货对冲 🔴 → P2(#267/#395 数据面已落地)

- 数据面已落地:#267 EOD 主连入缓存/可发布 + #395 tushare 化(fut_basic 合约登记 / fut_daily 日线主源 / fut_trade_cal 落库,主连双源对照 2025 全年一致);IF/IC/IM 在中金所;
- 真正成本在多资产对冲组合回测(换月 / 贴水 / 保证金;`futures_tsmom` 只是
  单腿趋势模拟器);
- **实盘侧触碰「单市场(A 股或期货二选一)」架构约束**,研究域可先行,
  实盘化需用户拍板。

## 路线 D:工程升级 🟡 → P1(#266 已合并,零新增数据)

- 平台已有:LW 协方差 / ERC / vol targeting / 风险贡献上限 / 回撤降风险;
- #266 已合并:风险因子中性化约束 + max IR 加权 allocator 已可用;剩余增量
  = 行业市值中性化 + 货币 ETF 现金 sleeve。

## 当前证据门(2026-09-13 复核,门规则不变)

1. 一切策略结论必须走完整晋级链:研究 → 回测 → OOS(#57)→ 模拟 → 影子 →
   小资金;screen 门 rank_ic 取绝对值只证「信号存在性」,方向责任在因子
   preference 与权益复测(#245 用户决策)。
