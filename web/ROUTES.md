# FinDashboard Web 路由与操作契约

工作区从课题开始。工作总览展示最近课题、待查运行及数据发布。一级导航固定为课题、数据基座、任务与审计、实盘、设置。研究版按研究 gateway 的能力展示课题、数据基座、任务与审计、设置，并以研究总览承接根路径。高级工具从侧栏、课题和研究总览可达。

## 页面首屏、详情与操作

| 页面 | 主任务与必需信息 | 高级操作或详情 | 使用者与显式操作 |
| --- | --- | --- | --- |
| 工作／研究总览 | 继续课题、分辨近期失败和数据可用性 | 进入运行、发布或任务详情 | 所有用户，只读 |
| 课题 | 识别问题、目标版本、证据缺口和下一步 | 轮次、研究记忆、版本与纠正 | 研究者，保存与启动分开 |
| 数据基座 | 确定覆盖、已发布版本及补数缺口 | 分类操作、源质量、交易日历、逐标的 | 数据操作员，预览后显式提交补数／发布 |
| 高级工具 | 按任务找到已有工具 | 进入对应页面 | 研究者，工具索引只读 |
| 因子实验室 | 选择因子、查看可用性和筛选结果 | 特征快照、截面、冻结实验 | 研究者，显式冻结或启动实验 |
| 策略 Studio | 识别版本、数据要求、配置和校验阻塞 | 版本 diff、结构化高级字段 | 研究者，保存、发布和执行独立 |
| 探索回测 | 选预设并查看输入、时间窗、结果 | 高级参数、历史、预设库 | 研究者，显式启动探索 |
| 研究运行 | 分辨排队、执行、拒绝及可读结果 | 版本、产物、窗口、决策和成交 | 研究者，提交前预检、执行及 replay 显式触发 |
| 正式实验 | 分辨执行状态与 OOS 结论 | 协议、样本窗、阈值、揭盲证据 | 研究者，最终揭盲须确认 |
| 组合与风险 | 查看权重、硬约束与三档可行性 | 协方差、费用、诊断和离散交易 | 研究者，只有正式组合流水线产出研究订单 |
| 模拟盘 | 查看模拟账户、当前会话和阻塞 | 订单、成交、持仓、资本、风险、审计 | 模拟操作者，显式开启或提交目标 |
| 研究报告 | 阅读结论、基准、口径和证据限制 | 图表、决策详情、CSV／Markdown | 研究者，只读与导出 |
| 策略说明书 | 查同一冻结输入的生效规则 | 精确版本、缺失条目和证据来源 | 研究者，只读 |
| 研究资料 | 查正式结论和支持证据 | 历史轮次、版本及来源 | 研究者，只读 |
| Agent 接入 | 核对端点、能力范围与课题续接 | 可复制接入步骤与一次性凭据处理说明 | 研究者，宿主管理凭据 |
| 任务与审计 | 确认执行阶段、停滞和失败原因 | attempts、时序、日志、归档与产物 | 研究者；审计读依独立权限，任务取消须显式触发 |
| 设置 | 核对当前偏好、配置作用域和生效时间 | Data Base、Agent 接入、脱敏诊断 | 当前用户或实例操作员，写宿主凭据使用控制台或 CLI |
| 实盘仪表盘、持仓、成交 | 核对真实账户、内核和数据来源 | 时间戳、成交及核对详情 | 实盘操作者；监控操作只读 |
| 实盘订单与控制台 | 查询订单及 Kill Switch 实际状态 | 订单、核对差异与实盘审计 | 实盘操作者；下单、撤单、档位切换沿用现有确认 |
| 部署能力提示及 404 | 恢复有效访问 | 原 URL 可浏览器复制 | 所有用户，只读 |

## 一致的恢复行为

- 主流程使用课题、列表或预设选择定位对象。高级跳转支持既有 ID 深链。普通路径无需手填 ID、配置键或系统文件路径。
- 显式预览当前范围、冻结版本与失败原因。保存、发布和执行分别提供操作。过期预览必须重新生成。
- 延迟获取采用加载骨架。空列表给出可达入口。可恢复错误保留当前输入和重试动作。权限、数据或部署门槛以阻塞状态呈现。
- URL 中已建立的对象、筛选及页签条件在进入详情和浏览器返回时可恢复。需要分页的数据通过列表查询与详情展开，证据链接携带对应的冻结引用。
- 高风险操作的确认、取消和错误恢复使用隔离或模拟接口验证。它们对应 `phase1_doc.md` §3.4 的账户、订单、撤单和核对步骤。
- 键盘可用跳到正文、收展菜单、语义链接和蓝色焦点。导航语汇、总览、新工具页和部署提示提供中英，亮暗遵从 [设计规范](DESIGN.md)。窄屏使用抽屉，独立表格在内容区横向滚动。

路线和新旧交互对应关系也作为 #527 的浏览器验收输入。回滚由对应 PR 恢复路由和前端 token。回滚前可继续用原 `/positions`、`/orders`、`/fills`、`/control` 和研究深链访问。
